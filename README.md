# MotoRuta · planificador web

Planificador de rutas en moto: rutas arrastrables, tipo de cada carretera, rutas automáticas con
curvas (viajes de varios días y rutas de un día), etapas con dónde dormir, tiempo, gasolineras con
precios y zonas protegidas en pistas.

Abrir: https://gonzalobolado.github.io/motoruta-web/

Datos: © colaboradores de OpenStreetMap (ODbL), OpenFreeMap/OpenMapTiles, VersaTiles, Valhalla
(FOSSGIS), Photon, Open-Meteo, Ministerio para la Transición Ecológica (precios de carburantes).
